# SOFiSTiK_CADINP

Лабораторный практикум «Расчёт мостовых конструкций в SOFiSTiK на языке CADINP»
(дисциплина «Расчётные комплексы проектирования мостовых сооружений», СПбГАСУ).
**Черновик для апробации.**

Онлайн-версия: https://knvspb.github.io/SOFiSTiK_CADINP/

## Структура

| Путь | Содержимое |
|---|---|
| `index.qmd` | Предисловие |
| `ch01…ch04_*.qmd` | Теоретические главы |
| `ch05_*.qmd` … | Лабораторные работы |
| `code/` | Коды примеров (`*.dat`, SOFiSTiK 2025) |
| `figures/` | Рисунки |
| `syntax/cadinp.xml` | Подсветка синтаксиса CADINP |
| `_quarto.yml` | Настройки книги (Quarto) |

## Сборка

Сайт собирается автоматически (GitHub Actions) при каждом изменении в `main`.
Локально: `quarto preview`.
